# 2D Arcade Game – Unity

A 2D arcade-style game developed using Unity and C#. The game is inspired by the gameplay style of Flappy Bird and includes multiple gameplay features such as character selection, difficulty levels, collectibles, scoring, rewards, obstacles, and timer-based gameplay.

## Project Overview

The player controls a character and navigates through obstacles while collecting items and achieving the highest possible score.

The game provides different gameplay options and progression features to make the experience more interactive and challenging.

## Gameplay Features

- Keyboard-based player control using the Spacebar
- Multiple difficulty levels
- Optional timer-based gameplay
- Character selection through an in-game shop
- Multiple playable characters
- Collectible items
- Score system based on collected items
- Rewards based on the player's score and collected items
- Obstacles and collision mechanics
- Game Over system
- High Score tracking
- Start Menu
- Sound effects
- Character and gameplay animations

## Technologies

- Unity
- C#
- 2D Game Development

## Main Game Systems

### Player Control

The player controls the character using the Spacebar to navigate through the game environment and avoid obstacles.

### Difficulty Levels

The game includes multiple difficulty levels that provide different challenges for the player.

### Character Shop

Players can access an in-game shop where they can choose between multiple characters.

### Collectibles and Scoring

Players can collect items throughout the game. The collected items contribute to the player's score and can be used to determine rewards.

### Timer Mode

The game includes an optional timer mode where the player can choose to play with a time limit.

### Obstacles

The player must navigate around obstacles while maintaining control of the character.

### Rewards

Players receive rewards based on their performance, including the items collected and the achieved score.

## Game Flow

1. Start the game from the main menu.
2. Select a character from the available characters.
3. Choose the desired difficulty level.
4. Optionally enable the timer mode.
5. Start the game and control the character using the Spacebar.
6. Avoid obstacles and collect items.
7. Earn points based on collected items.
8. Receive rewards based on the achieved score.
9. Continue playing to improve the high score.
